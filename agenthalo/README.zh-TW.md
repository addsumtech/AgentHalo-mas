# AgentHalo

<img src="assets/icon.png" width="128" alt="AgentHalo">

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Español](README.es.md)

陪伴 AI 工作的安靜桌面夥伴。

AgentHalo 顯示工作中和等待中的主任務，點擊即可回到對應任務。內含 20 套角色、動畫與聲音，背景子任務不單獨顯示。

目前整合能力見[專案說明](../README.md)，實際驗證範圍見[驗證紀錄](../docs/INTEGRATION-FIXES-2026-09-07.md)。

## 開發

Node.js >= 22.12.0

```sh
npm ci
npm start
npm test
npm run build:mac
```

[AgentHalo Issues](https://github.com/addsumtech/AgentHalo/issues)
