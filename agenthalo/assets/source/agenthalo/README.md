# AgentHalo 图标

使用内置 imagegen 生成；用户认可风格并要求正对用户。`icon-master.png` 为正面透明 PNG，运行图标由 sips 等比导出；菜单栏为同一光环与眼睛的 SVG 简化标记。

## 生成提示词

Production macOS app icon for AgentHalo, a quiet desktop companion beside people while AI agents work. Warm ivory rounded-square tile, sea-glass teal soft-clay companion, friendly dark eyes, small calm smile, one floating halo, restrained depth, clean at small sizes, no text, transparent exterior.

## 用户修订

Change only the viewpoint to directly front-facing: symmetric face, level equal eyes, centered smile, balanced body and arms. Preserve the halo, palette, materials and expression. Remove the exterior checkerboard and retain actual alpha transparency.
